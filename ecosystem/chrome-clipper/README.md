# HaoRan · 转载到我的网站

在 Chrome 中正常打开你自己的公众号文章，点击扩展里的「转载到我的网站」，自动提取标题、完整正文和图片，保存为网站文章草稿，完成后自动打开网站编辑器。

## 首次安装与配置

1. 将下载的 ZIP 解压。打开 Chrome 的扩展管理页 `chrome://extensions/`。
2. 开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 `chrome-clipper` 文件夹。
3. 在 Chrome 扩展菜单中固定「HaoRan · 转载到我的网站」。
4. 在网站后台「设置 → 第三方发布」中找到 API Token 管理，创建一个用于浏览器转载的 Token，并复制到扩展设置。无需提供公众号密码。
5. 网站地址填写你的网站首页地址。本地开发使用 `http://127.0.0.1:3001`；线上使用实际 HTTPS 域名。点击「保存设置」，允许扩展连接该网站。Token 仅保存在当前浏览器的本地扩展存储中。

## 每篇文章的操作

1. 在 Chrome 中打开公众号原文，确保标题与完整正文可正常阅读。如微信要求验证，由你在原文页面正常完成。
2. 点击扩展图标，再点击「转载到我的网站」。标题自动提取，无需填写或复制正文。
3. 扩展上传图片并创建网站草稿；成功后自动打开网站编辑器。若存在图片或媒体未完整导入，会先展示具体提示，再由你点击「编辑网站文章」。
4. 核对内容后点击「发布到网站」。发布后仍可编辑。

## 保留内容与限制

- 公众号使用页面自身的正文区域，完整提取段落、标题、列表、引用、表格、代码块和图片，不运行正文摘要算法。
- 网站收到正文后进行安全清理、保留原文链接，并保存草稿。浏览器模式不会再次由网站服务器请求微信文章。
- 微信图片优先识别 `data-src`，包括尚未滚动加载的图片。每张图片最多 10 MB，图片下载失败会保留原链接并明确提示。
- 音视频和小程序暂不复制播放器，网站保留原文入口并提示。
- 验证页、空正文或提取错误不会创建网站文章。
- 普通网页仍支持现有 Readability / Markdown 采集；本扩展主要针对公众号转载，其他域名图片可能需要单独授权。
- 扩展只在你主动点击转载时读取当前页面。预设图片权限限于微信图片域名，连接个人网站的权限在保存设置时单独申请。

## 验证状态

公众号结构样例、完整正文保留、图片 URL 替换、浏览器内容入库和失败路径已有自动测试。具体公众号文章的最终验收，需要你在能正常阅读该文的 Chrome 中点击扩展完成。
